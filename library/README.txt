THƯ VIỆN ÂM THANH CỦA BẠN (không bắt buộc)
==========================================
Tool tự tạo sẵn nhạc, âm nền và hiệu ứng (thư mục _generated, tạo lúc chạy setup.bat), nên không có file nào cũng chạy được.
Muốn hay hơn thì bỏ file của bạn vào đây, tool sẽ ưu tiên file của bạn:

  music\<mood>\*.mp3|wav    mood: calm_normal, uneasy, tension_rise, dread, chase, aftermath, host
                            (nhiều file trong 1 thư mục thì tool dùng lần lượt)
  ambience\<tên>.mp3|wav    tên: room_tone, night_outside, forest, rain, wind, storm, bus, car, highway, hum,
                            fridge, clock, fire, tv_static, basement, crowd_far
  sfx\<tên>.wav|mp3         tên: hit, screech, riser, whoosh, knock, bang, door_creak, footsteps, phone_buzz,
                            notification, heartbeat, static_burst, switch, lights_out, thud, glass_tap, bus_brakes,
                            door_hiss, car_door, breath, whispers, bell, music_box, dog_bark, scrape

Chỉ dùng âm thanh có giấy phép rõ ràng: YouTube Studio > Audio Library (an toàn nhất), Pixabay (đọc giấy phép từng file).
Tab "4. Âm thanh" trong app cho nghe thử từng loại.
